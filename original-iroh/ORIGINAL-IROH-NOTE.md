# Original Iroh 0.3.0 — preserved here

This directory is Felix Maier's original **Iroh 0.3.0** (2018), preserved
here for reference, exactly as he shipped it. Nothing in here has been
changed — not a line of code, not a word of the docs.

IrohRedux is the fork that builds on it. The core idea — intercept, record
and analyze JavaScript at runtime, then change it while it runs — is Felix
Maier's. IrohRedux fixes and extends that idea; the original stays here so
anyone can see where it started.
